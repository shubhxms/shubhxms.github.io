## Ideas

- [Berkeley Graphics](https://usgraphics.com/), Wikipedia and airport signage, for the density.
- Books: the title page up front (this is the second edition), drop caps, and notes in the margin instead of at the bottom.
- [joodaloop](https://joodaloop.com/inventions), for the table of contents across the top of a page.
- Newspapers, for the printer's marks beside pages that don't open with a heading.
- [adammaj.com/reading](https://adammaj.com/reading), for [Core](/core).
- [ankitkr0.com](https://www.ankitkr0.com/), for the covers on the [Shelf](/shelf).

## Type

- [Crimson Text](https://fonts.google.com/specimen/Crimson+Text) for the text.
- [Space Mono](https://fonts.google.com/specimen/Space+Mono) for the sidebar, labels and tables.
- [Urbanist](https://fonts.google.com/specimen/Urbanist) for headings inside a page.
- [Pinyon Script](https://fonts.google.com/specimen/Pinyon+Script) for the drop caps.

## Build

- Built with [Hugo](https://gohugo.io), on a theme written for this site, and hosted on GitHub Pages. The source is on [GitHub](https://github.com/shubhxms/shubhxms.github.io).
- Maths is set with [KaTeX](https://katex.org).
- The [feed](/feed) comes from a small Cloudflare Worker.
- The footer of every page shows the last commit that changed it.
- Press ⌘K (Ctrl-K) to search or jump anywhere.
